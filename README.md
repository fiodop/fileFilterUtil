# FileFilterUtil

## 📌 Описание проекта

**FileFilterUtil** — это утилита на Java для фильтрации содержимого текстовых файлов.
Утилита принимает на вход несколько файлов, содержащих целые числа, строки и вещественные числа, и распределяет их по типам в отдельные выходные файлы.

* Целые числа → `integers.txt`
* Вещественные числа → `floats.txt`
* Строки → `strings.txt`

### Основные возможности:

* Чтение нескольких входных файлов.
* Разделение данных по типам и запись в разные файлы.
* Настройка пути для выходных файлов (`-o`).
* Настройка префикса для имён выходных файлов (`-p`).
* Режим добавления (`-a`) в существующие файлы.
* Два режима статистики: краткая (`-s`) и полная (`-f`).
* Обработка ошибок без падения программы.

Файлы результатов создаются **только при наличии данных соответствующего типа**.

---

## 🚀 Примеры запуска

### Запись результатов в папку с префиксом

```
java -jar fileFilterUtil-1.0-SNAPSHOT.jar input1.txt input2.txt -o /some/path -p result_
```

Создаст файлы:

* `/some/path/result_integers.txt`
* `/some/path/result_floats.txt`
* `/some/path/result_strings.txt`

---

### Режим добавления к существующим файлам

```
java -jar fileFilterUtil-1.0-SNAPSHOT.jar input1.txt -a
```

---

### Выбор статистики

* Краткая статистика:

```
java -jar fileFilterUtil-1.0-SNAPSHOT.jar input.txt -s
```

* Полная статистика:

```
java -jar fileFilterUtil-1.0-SNAPSHOT.jar input.txt -f
```

---

## 📊 Статистика

* **Краткая:** количество элементов каждого типа.
* **Полная:**

  * Числа: минимальное, максимальное, сумма, среднее, количество элементов
  * Строки: минимальная длина, максимальная длина, количество элементов

## ⚙️ Требования к системе

* **Java:** 17
* **Система сборки:** Maven 3.8+
* **Зависимости:** Lombok 1.18.38, стандартная библиотека Java

---

## 🔨 Сборка и запуск

### Клонировать репозиторий

```
git clone https://github.com/fiodop/fileFilterUtil.git
cd fileFilterUtil
```

### Сборка с помощью Maven

```
mvn clean package
```

### Запуск утилиты

```
java -jar target/fileFilterUtil-1.0-SNAPSHOT.jar <input_files> [опции]
```

---

## 🛡️ Обработка ошибок

* Проверка существования входных файлов и корректности директорий.
* В случае ошибки выводится информативное сообщение.
* Если продолжить выполнение невозможно, программа сообщает об этом пользователю.

---

## 📎 Примечания

* Файлы результатов создаются **только при наличии данных** соответствующего типа.
* Режим `-a` добавляет данные в файлы, не перезаписывая их.
* Пустые строки во входных файлах игнорируются.
